AI Music Mastering Suite v6.1

Command-line DSP · LUFS · true peak · mid/side · provenance

A Python mastering chain you run locally: set a target loudness (default −14 LUFS), a true-peak ceiling, and an optional JSON chain, then write a mastered WAV with a processing log. It can run models in series or in parallel, export a loudness-matched original for A/B, and record hashes and loudness at each step. No keys or secrets are included.

Install: pip install numpy soundfile pyloudnorm scipy. Then: python3 ai_mastering_suite_v61.py --input song.wav --output mastered.wav.
