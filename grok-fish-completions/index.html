Grok CLI Fish Completions

A fish completions script for the grok command

This is a Fish shell completions file, not a program you run. It teaches the fish shell how to tab-complete grok commands, flags and subcommands (sessions, plugins, worktrees, and more). No keys or secrets are included.

To use it locally, copy grok.fish into your Fish completions directory, for example ~/.config/fish/completions/.
