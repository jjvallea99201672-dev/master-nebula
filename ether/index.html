Ether

Four faces, one medium

Ether is a small thought-and-record protocol: transmit a thought, resonate against stored records, and keep a local store called Akasha. The wire format is the same in every face: a four-byte ETHR magic, a big-endian length, and a JSON payload. This hub gathers the pieces that talk that language.

ether.py v6.2

The hardened server: strict request validation, bounded framing, idle and connection limits, rate limiting, an atomic Akasha store, optional TLS, and a small CLI (serve, send, demo). There is no authentication beyond optional client certificates. No keys or hardcoded secrets are in the file; TLS certificate paths are CLI arguments. Not a hosted service — you run it locally.
