Real LLM integration and deep active-inference mastering — historical source

A local generative mastering/composition script from the NebulaSystem line: motif-style synthesis plus optional OpenAI or Anthropic streaming, with a demo that writes a WAV and a history log under masters_v463/.

API keys are read only from OPENAI_API_KEY and ANTHROPIC_API_KEY, with no defaults. If a key or package is missing, the script is meant to warn and continue in a local mode rather than ship a key. The original file called log.warning before the logger existed, so a missing optional package crashed on import; this published copy moves the logger setup above those imports. The inbox original is unchanged.

This is source for study and local use, not a hosted service. It was not run against any external API here. python3 -m py_compile succeeds. No keys are included.
