Lattice Keeper v0.40-5

JWT rotation, genesis anchor, fail-closed config

An earlier Lattice Keeper auth release than v0.65: JWT access and refresh rotation with atomic Lua consume, a genesis anchor on every token, Argon2 password hashes, a Redis-based rate limiter, and refresh-theft revoke-all. Not deployed, so not binding.

JWT_SECRET, LATTICE_KEEPER_PASSWORD_JAY_VALLEA, and LATTICE_KEEPER_PASSWORD_MOJO are read from the environment. There are no default secrets; the module raises a clear error if any of those is missing or empty. Full source, readable and downloadable. No keys are included.
