Lattice Keeper boot fragment

A short init snippet, not a complete program

A 394-byte fragment that loads a genesis resonance, boots a nonce, and starts a keeper “with Icecast signing from v0.61.” It is not a runnable script on its own: LatticeKeeper and get_lattice_client are not defined or imported here. A comment says the vault token is already revoked; no token or key is in the file.

Download the .py
from src.lattice_keeper.secrets import load_genesis_resonance, boot_nonce nonce = boot_nonce() secret = load_genesis_resonance() # already revoked Vault token keeper = LatticeKeeper(client=get_lattice_client(), namespace="{lattice}") secret.use(lambda mv: keeper.init_from_seed(bytes(mv))) # bytes(mv) if keeper wants bytes secret.wipe() keeper.start() # now with Icecast signing from v0.61
