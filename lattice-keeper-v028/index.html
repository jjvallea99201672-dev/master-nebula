Lattice Keeper v0.28

Fully restored, enhanced and patched · an earlier single-file build

A single-file aiohttp Lattice Keeper (post-quantum RWA tokenization, a forensic auditor axis, and an AI guardian layer). This is earlier than the v0.30 package, v0.65, and v1.0 already on this site, which are left in place. It is not a hosted service — you run it locally.

LATTICE_API_KEY is required and has no default. No keys or tokens are in the file. If you run it, it may write signing keys under ./pqc_keys. The genesis hash fd0adf90… is the same public forensic anchor family as the later builds, labelled CRC-2026-001, not a private key.
