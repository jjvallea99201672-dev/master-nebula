Lattice Keeper v1.0

Production-ready RWA tokenization engine · fixes vs v0.34

A later Lattice Keeper than the v0.65 and v0.40-5 pages already on this site, which are left in place. This build is an aiohttp service: a forensic genesis anchor, a persistent Merkle tree, optional ML-DSA-65 and Ed25519 signing, a guardian policy, and anti-fork gossip. It is not a hosted service — you run it locally.

LATTICE_API_KEY is required and has no default. No keys or tokens are in the file. If you run it and the signing libraries are installed, it will generate Ed25519 and ML-DSA-65 key files at paths you can set with environment variables (defaults are ed25519_seed.bin and ml_dsa65_*.bin in the working directory). The genesis hash fd0adf90… is the same public forensic anchor family as v0.65, labelled CRC-2026-001, not a private key.
