Framing

A React client that mirrors ether.py

This UI speaks the ETHR length-prefixed JSON frame protocol used by ether.py. You point it at a local WebSocket (default ws://127.0.0.1:8765), send a thought, and read hits, field energy, and nebula spread. The records API is optional and fails quietly when it is not there. There is a live build at ether-framing/. No keys are included.
