Lattice Keeper v0.30

Operator-signed policy · 2026-10-21

The hardened v0.30 package (2026-10-21): a signed-record HTTP service with hybrid Ed25519 + ML-DSA-65 signatures, optional ML-KEM-768, a signed hash-chained audit log in Redis, and an operator-signed policy that only an offline operator key can change. ESP32 firmware guardian_v030 is included. This is later than the single-file v0.28, and earlier than v0.65 and v1.0; those pages stay in place.

No private keys are in this tree. .env.example and firmware/guardian_v030/secrets.example.h are placeholders only. LATTICE_API_KEY and related secrets have no defaults. The server is written to refuse operator private keys in KEYS_DIR. The genesis hash fd0adf90… is the public forensic anchor, not a private key. A zip of the same tree is ready to upload as lattice-keeper-v030.zip.
